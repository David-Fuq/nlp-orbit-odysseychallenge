# PR-04: the model. CPU-only torch -- the default PyPI wheel can pull a
# multi-GB CUDA build for no benefit. The extra index plus the "+cpu" local
# version pin make a plain `pip install -r requirements.txt` resolve the CPU
# wheel without anyone remembering a flag. --extra-index-url (not --index-url)
# so everything above still comes from PyPI. No numpy: torch's "Failed to
# initialize NumPy" import warning is expected and harmless here.
--extra-index-url https://download.pytorch.org/whl/cpu
torch==2.14.1+cpu
